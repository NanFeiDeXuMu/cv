## 2. Task 1：Harris 参数实验

实现文件：`harris_corner.py`。使用 `cv2.goodFeaturesToTrack`，显式启用 `useHarrisDetector=True`，避免使用默认的 Shi–Tomasi 检测器。所有组固定 `blockSize=3`、`k=0.04`，并设置 `maxCorners=0`，避免人为数量上限影响比较。

Harris 响应为：

$$R = \det(M) - k\,\operatorname{trace}(M)^2$$

`qualityLevel` 相对于图像中最强的角点响应设置筛选阈值；`minDistance` 控制保留角点之间的最小欧氏距离。

| 实验组 | qualityLevel | minDistance / px | 角点数 | 相对基准减少 |
|---|---:|---:|---:|---:|
| base | 0.01 | 1 | 14,719 | — |
| high_quality | 0.20 | 1 | 894 | 93.93% |
| large_distance | 0.01 | 20 | 1,472 | 90.00% |

基准组在砖缝、树叶等纹理区域保留大量密集角点。提高质量阈值后，砖墙中的多数弱响应消失，较强的窗框、屋檐和部分树叶角点保留。增大最小间距后，砖墙和树叶仍有角点，但密集簇明显变稀疏。提高阈值与增大间距作用不同，不能仅根据最终数量判断检测质量。

## 3. Task 2：Lowe 比率检验

实现文件：`ratio_test.py`。SIFT 提取关键点和描述子，使用 L2 距离的 BFMatcher 查询两个最近邻。设最近邻为 `m`、次近邻为 `n`，仅在以下条件成立时保留 `m`：

```python
m.distance < threshold * n.distance
```

使用乘法形式避免直接除以零。若近邻不足两个则跳过；若没有描述子或目标描述子不足两个，则明确报告无法完成该任务。

图 A 检测到 111,249 个关键点，图 B 检测到 107,571 个关键点，获得 111,249 组双近邻候选。

| 比率阈值 | 保留匹配数 | 占双近邻候选比例 |
|---|---:|---:|
| 0.60 | 170 | 0.153% |
| 0.75 | 1,234 | 1.109% |
| 0.90 | 15,625 | 14.045% |

![比率阈值与匹配数量](output/task2_ratio_curve.png)

匹配数量随阈值升高而增加，0.90 相比 0.75 的增幅尤其明显。输入中的窗格与砖墙具有重复纹理，较宽松阈值会保留许多相似候选。可视化中，高阈值对应更多跨行、跨列连线，0.90 的全量连线已明显遮挡图像。

通过比率检验的匹配不等于真实正确匹配。本实验没有人工标注的对应关系，因此不将上述数量作为准确率，也不声称 0.60 下每一条匹配都正确。0.75 是本题使用的折中阈值，后续仍需 RANSAC 几何验证。

## 4. Task 3：RANSAC 单应矩阵与图像对齐

实现文件：`alignment.py`。处理流程为：

1. SIFT + BFMatcher 获取双近邻匹配，使用 0.75 比率阈值筛选。
2. 通过 `queryIdx` 取得图 A 坐标，通过 `trainIdx` 取得图 B 坐标；均整理为 `float32`、`(N, 1, 2)`。
3. 调用 `cv2.findHomography(src_pts, dst_pts, cv2.RANSAC, 5.0)`。在估计前设置 OpenCV 随机种子为 0。
4. 按返回的内点掩码绘制匹配，将图 A 透视变换到图 B 的坐标系与画布尺寸。
5. 重叠区域按 0.5/0.5 加权叠加。使用几何覆盖掩码，在图 A 未覆盖的位置保留图 B 原像素，避免黑色填充使边缘变暗。

程序检查匹配数、矩阵有效性与内点数；如果不足以估计单应矩阵，会报告失败。

| 指标 | 结果 |
|---|---:|
| 图 A / B 的 SIFT 关键点数 | 75,227 / 61,766 |
| 比率筛选后匹配数 | 2,360 |
| RANSAC 内点数 | 1,429 |
| RANSAC 外点数 | 931 |
| 内点比例 | 60.55% |
| 内点平均重投影误差 | 2.108 px |
| 内点重投影误差中位数 | 1.903 px |
| 内点最大重投影误差 | 4.988 px |

得到的单应矩阵（图 A → 图 B，以下为舍入值）：

```text
H = [[ 0.67639200,  0.01005279, 91.12170525],
     [-0.08168618,  0.96244025, 33.24551797],
     [-0.00010660,  0.00000670,  1.00000000]]
```

重投影误差计算为：将图 A 内点通过 H 投影到图 B，以投影坐标与对应图 B 关键点之间的欧氏距离衡量误差。上述数值仅描述拟合所使用内点的几何残差，不是独立测试集误差或整幅图像的像素误差。

![对齐后的叠加图](output/task3_final_overlay.jpg)

主要海报轮廓和大字标题已经对齐，局部小字、纸张边缘及外围结构仍可见重影。一个全局单应矩阵只能描述共同的平面投影关系，无法保证所有局部细节一致；局部内容差异、非平面结构、匹配误差都可能造成残余重影。本次结果支持整体对齐有效，但不代表实现了无缝拼接。
